## Первый запуск в игре

28 сентября, профиль Gale `Default`, ObeliskRU выключен: игра не дошла до главного меню.
StartupAccelerator (`Delay Patching = On`) применяет патчи после загрузки плагинов, уже
за пределами обработки ошибок в Tolmach. Патч `TradersExtended.ConfigEditor.OnGUI` не
скомпилировался: HarmonyX 2.9 не размечает обработчик фильтра исключений
(`catch … when`), и ошибка `Incorrect code generation for exception block` в
статическом конструкторе `UnityEngine.GameObject` остановила загрузку сцены. Вторая
ошибка — `IndexOutOfRangeException` в LocalizationManager мода SleepSkip: он принял
`catalog/SleepSkip.json` за свой файл перевода.

Исправлено: методы с фильтром исключений и блоком `fault` не патчатся (тесты воспроизводят
отказ Harmony на таких методах; проба на реальных DLL из профиля нашла два `fault`-метода —
`Port.RunWhenReady` в MWL и `ReloadAfterAssetSync` в WackysDatabase, оба без потери перевода), каталоги называются `tolmach-<id>.json`, предупреждения о литералах
выдаёт сам транспайлер. Повторный запуск ещё не выполнен.

## Не проверено

- Запуск Valheim с исправленным пакетом: загрузка BepInEx, экраны модов, субтитры, смена
  языка, мультиплеер. Проверять нужно в двух конфигурациях: без другого пакета русского
  перевода и вместе с ним. План — [RUNTIME-CHECKLIST.md](RUNTIME-CHECKLIST.md).
- Фактический импорт через интерфейс или backend Gale, импорт в r2modman и загрузка
  на thunderstore.io. Раскладка проверена по исходному коду установщика Gale 1.22.3,
  формат — по правилам Thunderstore.
- Одновременная установка со старым локальным ValheimRussianPack. У модов разные GUID,
  поэтому загрузятся оба; старый нужно удалить.
- Пилот XUnity.AutoTranslator ([REUSE-DECISIONS.md](REUSE-DECISIONS.md)).
