# Проверки 0.2.0

Дата: 28 сентября 2026. Окружение: Windows 11, .NET SDK 9.0.318, Valheim 1.0.16,
профиль Gale `Default` с BepInEx 5.4.23.5, HarmonyX 2.9, Jötunn 2.30.2 и
JsonDotNET 13.0.4.

0.2.0 — переименование пакета в Tolmach: новые GUID плагина, имена сборки, DLL,
отчёта и пакета. Логика перевода и каталоги не менялись, поэтому проверки 0.1.3 по
поведению остаются в силе; для 0.2.0 повторены те, что затрагивает переименование.

## Выполнено

| Проверка | Результат | Что подтверждает |
|---|---|---|
| `Build.ps1 -OutputDirectory` | Успех: `Muratovnik-Tolmach-0.2.0.zip` и `SHA256SUMS` | Компиляция под новыми именами, тесты, сверка DLL и каталогов, сборка tcli, проверка пакета |
| NUnit (`dotnet test`) | 167 из 167, без пропусков | Поведение `Tolmach.dll` с настоящей Harmony на управляемых заглушках игры |
| Контроли проверки пакета | 1 корректный ZIP принят, 6 испорченных отклонены | Проверка в `Build.ps1` работает с новым именем DLL |
| Каталоги относительно 0.1.3 | 37 из 37 побайтно совпадают | Переводы не менялись |
| `python tools/validate.py` | 4022 утверждения, 0 ошибок | Отчёт побайтно совпадает с [0.1.3/validation.json](evidence/0.1.3/validation.json) |
| `pytest tests/test_validation.py` | 6 passed | Валидатор данных ловит 5 конкретных поломок |

Выпуск через release-kit повторяет эти проверки из закоммиченного кода: проверку
данных и pytest, аудит секретов и локальных ссылок по дереву и истории, сборку и
контроли пакета на готовом ZIP. Их журналы остаются в `.git/relkit/`, а в пакет
входит `build-receipt.json` сборки.

## Не проверено

- Запуск Valheim с пакетом: загрузка BepInEx, экраны модов, смена языка, мультиплеер.
  План — [RUNTIME-CHECKLIST.md](RUNTIME-CHECKLIST.md).
- Фактический импорт через интерфейс или backend Gale, импорт в r2modman и загрузка
  на thunderstore.io. Раскладка проверена по исходному коду установщика Gale 1.22.3,
  формат — по правилам Thunderstore.
- Одновременная установка со старым локальным ValheimRussianPack. У модов разные GUID,
  поэтому загрузятся оба; старый нужно удалить.
- Пилот XUnity.AutoTranslator ([REUSE-DECISIONS.md](REUSE-DECISIONS.md)).
