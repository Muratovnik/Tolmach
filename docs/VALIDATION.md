# Проверки 0.3.0

Дата: 28 сентября 2026. Окружение: Windows 11, .NET SDK 9.0.318, Valheim 1.0.16,
профиль Gale `Default` с BepInEx 5.4.23.5, HarmonyX 2.9, Jötunn 2.30.2 и
JsonDotNET 13.0.4.

0.3.0 — самостоятельный пакет: шесть новых каталогов (пять модов и субтитры игры),
шесть расширенных, правки вычитки в 17 каталогах, сырые строки, литералы в
конструкторах и модуль игры.

## Выполнено

| Проверка | Результат | Что подтверждает |
|---|---|---|
| `Build.ps1` | Успех: `Muratovnik-Tolmach-0.3.0.zip`, 43 каталога | Компиляция, тесты, сверка DLL и каталогов, сборка tcli, проверка пакета |
| NUnit (`dotnet test`) | 237 из 237, без пропусков | Поведение `Tolmach.dll` с настоящей Harmony на управляемых заглушках игры, в том числе каждая сырая строка и каждый шаблон всех каталогов |
| Контроли проверки пакета | 1 корректный ZIP принят, 6 испорченных отклонены | Проверка в `Build.ps1` работает на 43 каталогах |
| `python tools/validate.py --evidence` | 8286 утверждений, 0 ошибок | Отчёт — [0.3.0/validation.json](evidence/0.3.0/validation.json) |

| Литералы в IL установленных DLL | 318 из 318 | Каждый литерал — `ldstr` именно в указанном методе или конструкторе |

Сводка и хеши — [0.3.0/checks-0.3.0.json](evidence/0.3.0/checks-0.3.0.json).

Выпуск через release-kit повторяет эти проверки из закоммиченного кода: проверку
данных и pytest, аудит секретов и локальных ссылок по дереву и истории, сборку и
контроли пакета на готовом ZIP. Их журналы остаются в `.git/relkit/`, а в пакет
входит `build-receipt.json` сборки.

## Не проверено

- Запуск Valheim с пакетом: загрузка BepInEx, экраны модов, субтитры, смена языка,
  мультиплеер. Проверять нужно в двух конфигурациях: без другого пакета русского
  перевода и вместе с ним. План — [RUNTIME-CHECKLIST.md](RUNTIME-CHECKLIST.md).
- Фактический импорт через интерфейс или backend Gale, импорт в r2modman и загрузка
  на thunderstore.io. Раскладка проверена по исходному коду установщика Gale 1.22.3,
  формат — по правилам Thunderstore.
- Одновременная установка со старым локальным ValheimRussianPack. У модов разные GUID,
  поэтому загрузятся оба; старый нужно удалить.
- Пилот XUnity.AutoTranslator ([REUSE-DECISIONS.md](REUSE-DECISIONS.md)).
