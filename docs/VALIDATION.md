## Методы, которые Harmony не патчит

Запуск 0.6.0 записал в журнал `UI patch skipped` для четырех методов:
`TradersExtended.ConfigEditor.OnGUI` (фильтр исключений),
`More_World_Locations_AIO.Port.RunWhenReady`, `MyLittleUI.StationRepair.RepairOnHold` и
`HandleData.ReloadAfterAssetSync` из WackysDatabase OBJimporter (блоки `fault` в `MoveNext`
корутин). Текст терял только TradersExtended: заголовки окон редактора настроек торговцев,
которые OnGUI рисует через `GUI.Window`, оставались английскими, хотя в каталоге они есть. Три
других метода показывают только ключи игры (`$msg_inuse`, `$msg_repaired`) или сообщение,
которого нет в каталогах.

Исправлено: тело такого метода по-прежнему не меняется, а вызываемые им методы показа
(`GUI.Window`, `Character.Message`, `Player.Message`, `MessageHud.ShowMessage`) получают префикс,
который переводит текст каталогом мода, только если прямой вызывающий — этот метод. Предупреждение
осталось лишь для случаев, когда текст каталога действительно не переводится; остальные методы
перечислены в `Tolmach.runtime.txt` с `notPatched=`, `callSites=` и `leftAsIs=`. Устройство —
в [ARCHITECTURE.md](ARCHITECTURE.md). У самих методов показа в игре (`GUI.Window`,
`Character.Message`, `Player.Message`, `MessageHud.ShowMessage`) обработчиков filter и fault нет:
проверено по IL их сборок.

Не проверено: 0.6.0 в игре, в том числе заголовки окон Traders Extended. План — раздел «Приёмка 0.6.0» в [RUNTIME-CHECKLIST.md](RUNTIME-CHECKLIST.md).

## Первый запуск в игре

28 сентября, профиль Gale `Default`, ObeliskRU выключен: игра не дошла до главного меню.
StartupAccelerator (`Delay Patching = On`) применяет патчи после загрузки плагинов, уже
за пределами обработки ошибок в Tolmach. Патч `TradersExtended.ConfigEditor.OnGUI` не
скомпилировался: HarmonyX 2.9 не размечает обработчик фильтра исключений
(`catch … when`), и ошибка `Incorrect code generation for exception block` в
статическом конструкторе `UnityEngine.GameObject` остановила загрузку сцены. Вторая
ошибка — `IndexOutOfRangeException` в LocalizationManager мода SleepSkip: он принял
`catalog/SleepSkip.json` за свой файл перевода.

Исправлено: методы с фильтром исключений и блоком `fault` не патчатся (тесты воспроизводят
отказ Harmony на таких методах; проба на реальных DLL из профиля нашла два `fault`-метода —
`Port.RunWhenReady` в MWL и `ReloadAfterAssetSync` в WackysDatabase, оба без потери перевода), каталоги называются `tolmach-<id>.json`, предупреждения о литералах
выдаёт сам транспайлер. Повторный запуск ещё не выполнен.
